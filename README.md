# Dyqani Online SQ/EN

Flutter Web e-commerce application prepared for Supabase and Vercel.

Features:
- Responsive SQ/EN storefront
- Product search and categories
- Product detail, size/color selection
- Favorites and cart quantities
- Supabase order submission
- Administrator login through a Supabase Edge Function
- Product create/update/delete protected by Row Level Security
- Vercel build configuration
